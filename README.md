# Imperial Atlas — Астрографический редактор M30

Интерактивная карта галактики в мрачной готической эстетике Warhammer 30K / Horus Heresy.

## Возможности
- Создание оригинальных звёздных систем с типом мира: улей, океанический, кузнечный, агромир, мёртвый, ледяной, джунглевый, пустынный, крепость-мир, демонический и др.
- Редактирование названия, типа, населения, особенностей, описания и размера системы.
- Фракции с настраиваемым цветом и описанием.
- Битвы: дата, силы сторон, победитель и хроника.
- Связи между системами.
- Удаление систем, фракций и битв.
- Панорамирование и масштабирование карты.
- Слои карты.
- Экспорт/импорт JSON.
- Автосохранение в localStorage.

## Запуск
Это полностью статический проект. Откройте `index.html` локально или включите GitHub Pages для репозитория.

## Данные
Кнопка «Экспортировать JSON» сохраняет текущую карту. Импорт позволяет переносить карту между браузерами.
